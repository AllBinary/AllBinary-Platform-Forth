                             AllBinary Platform Gforth (Forth)

What is it?

This repository contains code generated by the AllBinary Platform for support in Gforth (Forth).  
This repo is used to allow developers to skip the Gforth (Forth) code generation step.

What are some example games with this Gforth (Forth) code?

https://allbinary.itch.io (The downloads with "-forth" in the filename are Gforth (Forth) only builds. Currently that only includes nothing. Also the Gforth (Forth) builds are not available on Google Play or other stores.)
